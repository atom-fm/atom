# Front matter

Documentation supports three initial metadata fields:

| Field | Meaning |
| --- | --- |
| `title` | Sidebar and document title |
| `description` | Page metadata summary |
| `order` | Navigation position among siblings in the same folder; ties use the URL slug |

Previous and next links follow the sidebar hierarchy: a section landing page, its nested documents, then the next section. Order values can be reused in different folders.
